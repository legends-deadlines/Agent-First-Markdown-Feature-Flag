# MDFLAG

**Фича-флаги для AI-агентов. Без SaaS. Без API-ключей. Простые Markdown-файлы в вашем Git-репозитории.**

AI-агенты (Cursor, Claude Code, Copilot, Windsurf) пишут код и внедряют его прямо в ваш проект. Если код содержит ошибки, ломается всё приложение. Откат изменений сложен и занимает много времени.

Существующие инструменты (LaunchDarkly, Statsig, Flipt) недоступны для автономных агентов — они требуют регистрации на сайтах, API-ключей и настройки SDK. У агентов нет браузеров, email и банковских карт.

MDFLAG решает эту проблему, представляя фича-флаги в виде обычных Markdown-файлов в директории проекта. ИИ-агенты умеют работать с файлами — значит, они умеют работать и с MDFLAG.

---

## Главная идея

**ИИ умеет создавать файлы в Git, но не может регистрироваться в SaaS.**

Поэтому:
- Традиционные сервисы флагов (LaunchDarkly) = недоступны агентам.
- Git-ориентированные флаги (MDFLAG) = доступны агентам.

MDFLAG — первое решение, которое использует существующие возможности ИИ, вместо того чтобы обучать его сложным внешним интеграциям.

---

## Как это работает

**Без флагов:**
ИИ строит новую комнату, снося старую. Если новая комната выйдет кривой, вы останетесь вообще без жилья.

**С флагами:**
ИИ строит новую комнату рядом со старой. Вы сами решаете, в какой жить. Если с новой что-то не так — вы просто закрываете дверь и остаётесь в старой.

---

## Возможности

- **Agent-native**: Работает через MCP (Model Context Protocol) — без регистрации и API-ключей
- **Git-based**: Флаги хранятся как Markdown-файлы в репозитории и версионируются вместе с кодом
- **Защита целостности**: Проверка SHA-256 хешей предотвращает несанкционированные правки
- **Постепенная раскатка**: Включение флага для 5% → 25% → 100% пользователей
- **Мгновенный откат**: Изменение одной цифры в файле мгновенно выключает фичу
- **Контроль человеком**: Агенты создают флаги, люди управляют раскаткой

---

## Быстрый старт (CLI)

```bash
# Создание флага (0% rollout)
mdflag create --name new-checkout --hypothesis "Повышение конверсии на 5%"

# Изменение раскатки (25%)
mdflag rollout --name new-checkout --percentage 25

# Проверка целостности хешей
mdflag verify

# Список всех флагов
mdflag list
```

---

## Использование в коде (Go)

```go
import "github.com/legends-deadlines/mdflag/pkg/mdflag"

client, err := mdflag.New(".mdflag")
if err != nil {
    log.Fatal(err)
}

if client.Enabled("new-checkout", userID) {
    // Ветка с новой фичей
} else {
    // Старая стабильная ветка
}
```
