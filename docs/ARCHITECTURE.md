# Архитектура проекта mdflag

## Общий обзор

Проект `mdflag` представляет собой единый Go-бинарник, объединяющий:
1. **MCP-сервер** (stdio) — для интеграции с AI-агентами (Cursor, Claude Code, Antigravity).
2. **CLI-инструмент** — для разработчика (`mdflag create`, `mdflag verify`, `mdflag hook`).
3. **Runtime SDK** — встраиваемую библиотеку для проверки статусов флагов в приложении.

Продукт рассчитан на соло-разработчика, работающего в связке с AI-кодинг ассистентом. Дистрибуция осуществляется через скачиваемый бинарник в GitHub Releases.

## Структура пакетов Go

- **`cmd/mdflag`**: CLI входная точка для всех субкоманд (`compile`, `validate`, `hook`, `mcp`).
- **`internal/flagstore`**: Загрузка, десериализация YAML/Markdown и парсинг трехсекционных флагов.
- **`internal/hashguard`**: Защита целостности файлов путем проверки SHA-256 хешей секций `AGENT_WRITABLE` и `HUMAN_CONTROLLED`.
- **`internal/runtime`**: Движок локального детерминированного таргетинга (процентный раскат, проверка `entityID`).
- **`internal/hooks`**: Генерация и установка локальных Git pre-commit хуков.
- **`internal/mcp`**: MCP-сервер для взаимодействия с AI-агентами по протоколу stdio.

## Локация файлов флагов

Все файлы флагов хранятся в централизованной папочке `.mdflag/` в корне репозитория (например, `.mdflag/new_payment_flow.md`).
